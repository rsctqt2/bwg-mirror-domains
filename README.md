## 主域名为什么打不开

不是搬瓦工跑路，也不是你的网络坏了，多数情况是 DNS 污染：域名在本地运营商的解析环节被干扰，要么解析到一个错误 IP，要么干脆超时。这个问题存在很多年了，官方的应对方式就是持续更换和增加镜像域名。

几个可行的对策，按省事程度排：

1. 直接使用当前可用的镜像域名（如 `bwh81.net`）；
2. 把本地 DNS 换成公共 DNS（8.8.8.8 之类），有时能绕开污染，但不是每次都管用；
3. 已经有账号的老用户不必焦虑，账号和 VPS 挂在服务上，不跟某个具体域名走，换入口登录即可。
